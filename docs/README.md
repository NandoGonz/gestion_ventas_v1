# Documentación del proyecto

La documentación de diseño, justificación, alcance, requisitos y modelo de datos está en el documento Word `Documento_Proyecto_Gestion_Ventas_V1.docx`, incluido en la raíz del paquete entregado.

- `API.md`: catálogo de endpoints, autenticación y ejemplos.
- `VALIDACION.md`: resultados y límites de las verificaciones realizadas.
- `diagrama_tablas.png`: diagrama entidad-relación de `usuarios`, `clientes`, `productos`, `ventas` y `detalle_venta`.
- `arquitectura.png`: interacción entre frontend, backend y base de datos.

El documento Word se considera la explicación técnica principal; los README complementan la instalación y operación.

La contraseña inicial de desarrollo se guarda únicamente en `backend/.env`; no se replica en la documentación ni en el código. La cuenta se crea al arrancar si el correo configurado aún no existe.
